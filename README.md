# ChatGPT Reading Toolkit

自用的 ChatGPT 网页阅读、导航和导出扩展。扩展不再读取或估算上下文 token。

## 功能

- 右侧对话时间线支持搜索、跳转和本地星标。
- 支持 `j` / `k` 跳转相邻消息，`gg` / `GG` 跳转首尾。
- 支持选择多条消息并导出 PNG、图片 PDF、可选择文字的打印 PDF 或 Markdown。
- 公式可复制为 LaTeX、Markdown 或 MathML / Word；MathML 不可用时自动回退为 Word 兼容 LaTeX。
- 按对话自动保存和恢复未发送草稿。
- 可调整正文宽度、字体大小、行高和段落间距。
- 页面处于后台时，可在 ChatGPT 回答完成后发送系统通知。
- 收起右侧面板后只保留“刷新”和“展开”按钮。

## 对话导出

1. 展开右侧面板。
2. 点击“选择”后在页面或时间线中选择消息，也可以点击“全选”。
3. 选择 PNG、PDF、MD 或打印。

导出说明：

- PNG 使用暗色 ChatGPT 风格，超长内容会自动拆分为多张图片。
- PDF 将 PNG 分片逐页写入，适合保持网页视觉效果。
- 打印 PDF 会打开打印页，文字、代码和公式可选择。
- Markdown 保留标题、列表、引用、代码块、表格、链接、图片和 LaTeX。

## 时间线

- 点击消息摘要跳转到原文。
- 点击星形按钮保存关键消息；顶部星形按钮只显示星标。
- 搜索框只筛选当前对话，不发送任何数据。

## 数据存储

- 设置保存在 `chrome.storage.sync`。
- 星标和草稿保存在 `chrome.storage.local`。
- 草稿按对话隔离，30 天后自动失效。
- 所有导出和公式转换均在浏览器本地完成。

## 安装

1. 打开浏览器扩展管理页。
2. 启用开发者模式。
3. 加载 `chatgpt-helper-extension` 目录作为未打包扩展。
4. 刷新已打开的 ChatGPT 页面。
