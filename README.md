# ChatGPT Reading Toolkit

一个面向 ChatGPT 的 Chrome / Edge 阅读、公式复制和对话导出扩展，基于 Manifest V3。

## 功能

### 公式复制

- 鼠标悬停时高亮可见的行内公式和块级公式，点击即可复制。
- 优先读取页面提供的 LaTeX 源码；缺少源码时，可从 KaTeX 或结构化 MathML 可靠还原公式。
- 支持不含特殊 LaTeX 命令的简单公式，例如 `F(ax-bz,ay-cz)=0`。
- 可在扩展设置中选择 LaTeX、Markdown 或 MathML / Word 复制格式。
- 不会把普通文本、无结构的伪 MathML 或辅助标签误当成可复制公式。

### 对话导出

- 页面右下角的“消息导出”面板显示当前对话的历史消息；点击列表中的消息即可选择导出内容。
- 面板默认收起，点击“展开”查看历史消息和导出按钮；收起不会清除已选消息。
- 点击“选择消息”后，也可在聊天正文中点选消息；蓝色外框会标记已选消息。点击“取消选择”会清空当前选择。
- 面板显示已选消息数量；没有选中消息时，PNG、MD 和打印按钮不可用。
- 支持导出 PNG、Markdown，以及通过浏览器打印生成可选择文字的 PDF。
- Markdown 导出保留标题、列表、引用、代码块、表格、链接、图片和 LaTeX。
- PNG 会保留网页视觉样式，超长内容自动拆分。
- 打印 PDF 会保留网页端代码块的语法高亮颜色，并将代码标题和代码正文分栏排版，提升代码阅读体验。
- 长回复按页面提供的消息单元识别，思考摘要不会被当作正式回答；未变化消息会复用文本识别结果，减少长对话页面的重复扫描。

### 阅读与草稿

- 正文宽度、字号、行高和段距可分别设为“原版”或自定义值。选择“原版”时，扩展会移除对应的样式覆盖，沿用当前 ChatGPT 页面提供的样式；它不是固定的像素或倍数。新安装默认四项均为原版，扩展更新不会清除已保存的旧自定义值。
- 可调整正文宽度、字体大小、行高和段落间距；字号按页面原有文字及公式大小成比例缩放，关闭时恢复原样。
- 按对话自动保存未发送草稿，并在返回对话时恢复。
- 草稿默认保留 30 天，可在扩展设置中关闭自动保存。

## 支持站点

- `https://chatgpt.com/*`
- `https://*.chatgpt.com/*`
- `https://chat.openai.com/*`

## 安装

1. 下载或克隆本仓库。
2. 打开 Chrome 或 Edge 的扩展管理页面。
3. 启用“开发者模式”。
4. 选择“加载已解压的扩展程序”。
5. 选择仓库中的 `chatgpt-helper-extension` 目录。
6. 刷新已打开的 ChatGPT 页面。

修改代码后，需要在扩展管理页面重新加载扩展，并刷新 ChatGPT 页面。

## 使用

1. 在右下角“消息导出”的历史对话列表中点选一条或多条消息，或点击“选择消息”后在聊天正文中点选。
2. 点击 PNG、MD 或打印导出已选内容；点击“取消选择”会清空选择。
3. 将鼠标移动到公式上查看高亮，点击公式按设置的格式复制。
4. 点击浏览器工具栏中的扩展图标可修改公式格式、阅读排版和草稿设置。

### 自定义排版

1. 打开扩展工具箱并启用“自定义排版”。
2. 正文宽度、字体大小、行高和段落间距分别设置。将某个滑块拖到最左端，右侧会以强调色显示“原版”；该项会沿用当前 ChatGPT 页面样式。其他滑块可以继续使用自定义数值，因此四项可以混合设置。
3. 点击“保存”应用设置。已有的自定义值会继续保留；要恢复某一项原版样式，需将对应滑块拖到最左端并保存。关闭“自定义排版”则整体停用扩展的排版调整。

保存设置后，当前 ChatGPT 聊天页会立即应用；如果页面尚未加载新版扩展脚本，扩展会刷新该聊天页以使设置生效。
启用自定义排版后，保存提示下方会显示正文识别信息，以及实际文字字号、行高和段距，便于排查页面结构变化；诊断信息不包含聊天文本。行高主要影响折行文字，单行内容的变化通常不明显。

## 数据与权限

- 设置保存在 `chrome.storage.sync`。
- 草稿保存在 `chrome.storage.local`，并按对话分别保存。
- 公式转换和对话导出均在浏览器本地完成。
- 扩展仅申请 `storage` 和 `clipboardWrite` 权限，并仅在上述 ChatGPT 域名运行。
