# ChatGPT Reading Toolkit

一个面向 ChatGPT 的 Chrome / Edge 阅读、导航、公式复制和对话导出扩展，基于 Manifest V3。

## 功能

### 公式复制

- 鼠标悬停时高亮可见的行内公式和块级公式，点击即可复制。
- 优先读取页面提供的 LaTeX 源码；缺少源码时，可从 KaTeX 或结构化 MathML 可靠还原公式。
- 支持不含特殊 LaTeX 命令的简单公式，例如 `F(ax-bz,ay-cz)=0`。
- 可在扩展设置中选择 LaTeX、Markdown 或 MathML / Word 复制格式。
- 不会把普通文本、无结构的伪 MathML 或辅助标签误当成可复制公式。

### 对话导航

- 在页面右侧显示当前对话的消息时间线。
- 支持搜索、跳转、星标消息和仅查看星标内容。
- 星标数据保存在浏览器本地。

### 对话导出

- 可选择一条或多条消息，也可以全选当前对话。
- 支持导出 PNG、图片 PDF、Markdown，以及通过浏览器打印生成可选择文字的 PDF。
- Markdown 导出保留标题、列表、引用、代码块、表格、链接、图片和 LaTeX。
- PNG 和图片 PDF 会保留网页视觉样式，超长内容自动拆分。

### 阅读与草稿

- 可调整正文宽度、字体大小、行高和段落间距。
- 按对话自动保存未发送草稿，并在返回对话时恢复。
- 草稿默认保留 30 天，可在扩展设置中关闭自动保存。

## 支持站点

- `https://chatgpt.com/*`
- `https://*.chatgpt.com/*`
- `https://chat.openai.com/*`

## 安装

1. 下载或克隆本仓库。
2. 打开 Chrome 或 Edge 的扩展管理页面。
3. 启用“开发者模式”。
4. 选择“加载已解压的扩展程序”。
5. 选择仓库中的 `chatgpt-helper-extension` 目录。
6. 刷新已打开的 ChatGPT 页面。

修改代码后，需要在扩展管理页面重新加载扩展，并刷新 ChatGPT 页面。

## 使用

1. 点击右侧“展开”打开对话导航。
2. 使用搜索、星标或消息摘要定位内容。
3. 点击“选择”后选中需要导出的消息，再选择 PNG、PDF、MD 或打印。
4. 将鼠标移动到公式上查看高亮，点击公式按设置的格式复制。
5. 点击浏览器工具栏中的扩展图标可修改公式格式、阅读排版和草稿设置。

## 数据与权限

- 设置保存在 `chrome.storage.sync`。
- 星标和草稿保存在 `chrome.storage.local`。
- 公式转换和对话导出均在浏览器本地完成。
- 扩展仅申请 `storage` 和 `clipboardWrite` 权限，并仅在上述 ChatGPT 域名运行。
