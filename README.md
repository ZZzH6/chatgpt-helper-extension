# ChatGPT Context Helper

ChatGPT 网页助手扩展，用于估算当前对话的可见 token 使用量，提供公式复制增强，并支持将选中的对话消息导出为暗色 PNG 图片。

## 功能

- 估算 ChatGPT 当前页面可见上下文的 token 数量。
- 支持设置提醒阈值和高风险阈值。
- 支持显示或隐藏每条消息的 token 估算。
- 鼠标悬停或点击公式时，可复制为 LaTeX 或 Markdown。
- 右侧面板支持真正收起，只保留刷新和展开按钮。
- 支持选择多条对话消息并导出为暗色主题 PNG。
- 导出图片支持文本、代码块、表格、已渲染公式和用户上传图片。
- 长对话导出时会根据 canvas 限制自动分片，避免单张超长图片模糊或失败。

## 公式复制格式

### LaTeX

- 输出单行 LaTeX，自动压缩公式中的换行和多余空白。
- 自动将 `\tag{2-13}` 转换为 Word 公式可识别的 `#(2-13)`。
- 适合粘贴到 Microsoft Word 公式编辑器。

### Markdown

- 保留 LaTeX 语法，适合 Markdown 渲染器、笔记软件或文档系统。
- 行内公式输出为 `$...$`。
- 行间公式、带 `\tag{}` 的公式，以及 `aligned`、`cases`、`matrix` 等环境输出为 `$$...$$` 块。

## 使用

1. 打开浏览器扩展管理页。
2. 启用开发者模式。
3. 加载 `chatgpt-helper-extension` 目录作为未打包扩展。
4. 打开 ChatGPT 页面后使用右侧面板、公式复制按钮和导出功能。

## 对话导出

1. 展开右侧面板。
2. 点击 `选择导出`。
3. 点击页面中的消息，或点击右侧消息列表，选择需要导出的内容。
4. 点击 `导出 PNG`。

导出说明：

- 导出样式为暗色主题。
- 用户消息保留为右侧深灰气泡，助手消息按正文样式展示。
- 表格会使用导出专用布局，避免网页横向滚动条被导入图片。
- 用户上传图片会尽量内联到 PNG 中；如果图片地址受浏览器安全策略限制，导出时会提示。
- 超长内容会导出为多张 PNG，文件名会追加 `part-01`、`part-02` 等后缀。
